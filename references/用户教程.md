# GrsAI 线上服装工具箱：给 Codex 的开箱教程

这个工具箱提供「文生图 → 人物换装 → 图片生视频」三种独立工作流。安装、导入、填写配置不调用生成接口；点击运行才会向 GrsAI 发送内容。需要一套能打开的 ComfyUI、自己的 GrsAI 账号与 Key，以及要使用的图片。

## 最省事：把仓库链接给 Codex

仓库：https://github.com/qwhsdwd/grsai-fashion-toolbox

把下面这段话发给自己的 Codex：

> 请读取 https://github.com/qwhsdwd/grsai-fashion-toolbox 的 README.md 和 SKILL.md，把整个仓库安装为 grsai-fashion-toolbox Skill。然后帮我找到正在使用的 ComfyUI，安装随附节点、导入三条工作流，并引导我在本机私下填写自己的 GrsAI Key。保留已有工作流和配置，先完成不收费的安装检查；生成任务等我提供素材和要求后再运行。

仓库已包含安装程序、节点源码、配置模板、三条工作流和本教程，不需要访问原作者电脑。也可以从 [Releases](https://github.com/qwhsdwd/grsai-fashion-toolbox/releases) 下载 Skill ZIP，解压后交给 Codex 读取 SKILL.md。

若要手动安装 Skill，下载仓库或把 Skill ZIP 解压后得到的 `grsai-fashion-toolbox` 文件夹放到：

- macOS / Linux：`~/.codex/skills/grsai-fashion-toolbox/`
- Windows：`%USERPROFILE%\.codex\skills\grsai-fashion-toolbox\`
- 如果用户自己设置了 `CODEX_HOME`，使用其下的 `skills` 目录。

确保 `SKILL.md` 就在该目录第一层。重新打开一个 Codex 聊天后，可以说：

> 请用 $grsai-fashion-toolbox 帮我安装和配置线上服装工具箱。

## 不使用 Skill：自己安装节点

从 [Releases](https://github.com/qwhsdwd/grsai-fashion-toolbox/releases) 下载并解压 `grsai-fashion-toolbox-nodes.zip`，不要只拿其中一个 JSON。双击对应系统的安装入口：

- Windows：`Windows安装.bat`。脚本会询问 ComfyUI 文件夹；便携版会优先使用其 `python_embeded`。
- macOS：`macOS安装.command`。需要可用的 Python 3；脚本会询问 ComfyUI 文件夹。
- Linux 或脚本未打开时：让 Codex 用合适的 Python 执行包内的 `install.py`。

选择包含 `main.py` 和 `folder_paths.py` 的 ComfyUI 根目录。Windows 便携包也可选择 `ComfyUI_windows_portable`。不要选模型目录或某一个工作流文件。若没有安装 ComfyUI，让 Codex 先协助安装；这个 ZIP 不是完整 ComfyUI 安装包。

高级安装命令：

```bash
python install.py --comfy-root "/实际/ComfyUI目录" --skip-config
```

安装器保留已有的 Key 和同名工作流。若已有同名流程被保留，可以把节点目录 `workflows` 里的新版 JSON 拖进 ComfyUI 使用。

## 配置自己的 GrsAI Key

1. 打开 [GrsAI 官网](https://grsai.com/)，注册或登录账号。
2. 进入控制台，在账号的 API Key 管理中创建、复制自己的 Key。页面名称以登录后显示为准。确认自己的账号可以调用需要的图片、视频模型；余额和计费规则以控制台为准。
3. 在 `ComfyUI/custom_nodes/ComfyUI-Cloud-Fashion` 中运行 `configure.py`，按提示选择节点并粘贴 Key，输入不回显。也可以用编辑器私下填写同目录的 `config.local.json`。

```json
{
  "api_key": "这里填写你自己的GrsAI Key",
  "base_url": "https://grsaiapi.com"
}
```

| 选项 | 填写的地址 |
| --- | --- |
| 全球节点 | `https://grsaiapi.com` |
| 国内节点 | `https://grsai.dakka.com.cn` |

`https://grsai.com/` 是网站首页，不能填到 `base_url`。不要追加 `/v1` 或填写某个图片 API 的完整路径。此包只支持 GrsAI 原生异步格式，不适用于任意其他供应商的 Key。

环境变量 `GRSAI_API_KEY` / `GRSAI_BASE_URL` 优先于配置文件。老用户的 `~/.config/grsai/credentials.json` 仍可继续使用，但节点目录存在 `config.local.json` 时优先使用新文件。

不要把 Key 写到聊天、提示词、节点文本或工作流 JSON。不要转发自己填过的 `config.local.json`。配置格式检查命令 `python configure.py --check` 不显示 Key、不联网，也不会验证远端余额或真实调用权限。

## 打开工作流

等待正在运行的 ComfyUI 任务完成，保存编辑，然后重启后台并刷新页面。

在工作流浏览器中展开：

**我的工具箱 → 05 线上工作流**

这里有三条：

1. `01 文生图－GPT Image 2.5（线上）`
2. `02 人物换装＋姿势参考－GPT Image 2.5（线上）`
3. `03 图片＋关键词＋姿势参考生视频－H3（线上）`

列表未显示时，把 `custom_nodes/ComfyUI-Cloud-Fashion/workflows` 中对应的 JSON 拖到 ComfyUI 画布。使用自定义用户目录或多用户时，拖入方式最直接。

如果只想单独添加节点，双击画布搜索「线上人物换装」，或从「我的工具箱 → 线上模型」选择对应节点。

## 第一次换装

分享版不含个人照片，先上传自己的素材：

| 图片角色 | 连接到 | 说明 |
| --- | --- | --- |
| 要换装的人物 | `person` | 决定脸、发型和身形 |
| 上衣或整套衣服 | `garment` | 平铺、挂拍或别人穿着的衣服均可 |
| 独立裙子或裤子 | `bottom` | 可选；接上后 garment 用于上衣 |
| 想模仿的姿势 | `pose` | 可选；只参考姿势，不替换人物身份 |

只有上传、没有接上线的可选图片不会参与生成。示例补充要求：

> 将上衣和裙子一起替换为参考款式，保留衣服的版型、花纹、纽扣和装饰。人物身份保持一致，完整露脸，上衣和整个裙摆同时可见。

`task_name` 保持「自动」，「重新生成批次」保持0，选择尺寸后运行。右侧保存节点会显示成品；报错后仍可能保留旧预览，要以本次执行成功状态为准。

AI 会参考衣服和姿势生成，不保证每处细节完全一致。先人工确认成品，再进入视频流程。

## 自动任务怎么用

- 换人物、衣服、下装、姿势图，或改提示词、尺寸、视频参数：自动新任务，不再手改编号。
- 相同内容重复点击：复用结果或继续查询，不再次提交相同任务。
- 同样素材想重新抽一版：把「重新生成批次」从0改成1；下一版改成2。
- 将内容改回之前的版本且批次相同：复用对应的历史结果。
- 查询失败或等待超时：保持内容和批次再运行即可续查。
- 提交后没有取得任务ID：先到控制台核对记录，不要盲目增加批次重复付款。

视频节点的 `seed` 若设置为每次随机或递增，也属于参数变化，会自动生成新任务；想安全续查时保持它固定。

## 生成视频

打开03流程，把已经确认的换装图上传到主图节点，填写动作描述，例如：

> 正面站姿，轻侧身扶胯，轻展裙摆，再回正微笑。动作舒缓，完整露脸和整套衣裙全程入镜。

默认10秒1080P；也可先选择更短时长检查效果。1080P最多10秒，480P/768P最多15秒。可再连接一张 `pose` 造型参考图。生成耗时、实际尺寸、视频时长和费用以服务返回及账号规则为准。

## 保存位置与常见问题

输出保存在你实际配置的 ComfyUI 输出目录下：`线上工具箱/01 文生图`、`02 人物换装`、`03 图片生视频`。任务缓存和续查记录在 `线上工具箱/任务记录`。

| 现象 | 处理 |
| --- | --- |
| 节点变红或显示缺失 | 确认节点装在当前运行实例的 custom_nodes 中；重启后台并检查日志 |
| 没看到工作流目录 | 直接拖入节点目录 workflows 中的 JSON |
| 提示没有选择图片 | 上传自己的图片；可选图需接上线才生效 |
| 401、认证失败、额度不足 | 核对自己的 Key、所选节点、账号余额和模型权限 |
| TLS、网络连接错误 | 检查网络；连接尚未发送请求的失败可保持内容重试 |
| 提示提交状态不确定 | 先核对控制台任务记录，不删除本地记录强行重试 |
| 换 Key 后仍用旧配置 | 检查是否有优先级更高的环境变量，或改错了另一套实例 |

安装脚本和节点已在 macOS 的 ComfyUI 环境与隔离测试目录验证；Windows 锁机制有模拟测试，尚未在 Windows 实机完整验收。遇到系统安装问题时，把不含 Key 的报错交给 Codex 排查。

转发时使用仓库链接或原始发布 ZIP。不要把填好 Key 的节点目录、任务记录、个人图片或生成成品重新打包给别人。
